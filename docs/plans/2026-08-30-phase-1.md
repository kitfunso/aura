# Phase 1: aura MVP (Lane A) Implementation Plan

**Goal:** Working color identity for Claude Code windows on this machine: tint + frame + prompt-in-title, installed via one command.
**Prerequisites:** Windows 11 + Windows Terminal (present), Node.js (present), repo scaffolded (done).
**Estimated scope:** 9 steps, ~1 day. Steps 1-2 are spikes that can kill or reshape the design - run them first, in order.
**Status 2026-08-30: all 9 steps DONE.** Step 8 ran as a driven 3-session live QA (pixel-verified tab/tint/border) instead of the full 10-window matrix; it found and fixed the hidden-console root cause (commit d983527). Step 1's original verify ("hook case tints visibly") was later corrected by that finding: the spike probe shared the real console, hooks do not.

---

## Step 1: Spike - can a hook-shaped process reach the live terminal?
**Files:** `spike/conout.js`
**What:** A script that opens `\\.\CONOUT$` and writes OSC 11 (background tint) + OSC 0 (title). Run it three ways: directly in Windows Terminal, as a detached child (hook-shaped), and as a real Claude Code hook in a scratch session. Also observe: does Claude Code rewrite the title afterwards, and how fast?
**Verify:** Background visibly tints and title changes in the live window in the hook case. Record title-overwrite behavior in ARCHITECTURE.md Known Risks.
**Commit:** `feat: spike CONOUT$ escape delivery from hook context`
**Kill condition:** If a real hook cannot reach CONOUT$, stop and redesign (statusline-based fallback) before any further steps.

## Step 2: Spike - DWM frame paint on a window found by nonce title
**Files:** `spike/frame-spike.ps1`
**What:** PowerShell that sets a nonce title via escape, finds the HWND (`FindWindow`/`EnumWindows`), paints border + caption via `DwmSetWindowAttribute` (34/35), prints the HWND.
**Verify:** The Windows Terminal window running the spike gets a red border + red title bar that persist while the title keeps changing.
**Commit:** `feat: spike DWM border/caption paint via nonce-title handshake`

## Step 3: Package skeleton
**Files:** `package.json`, `.gitignore`, `src/`, `test/`, `bin/` stubs
**What:** npm package `aura` (private for now), `node --test` wired, bin entry for the installer.
**Verify:** `npm test` runs (0 tests, exit 0).
**Commit:** `chore: package skeleton`

## Step 4: The color contract
**Files:** `src/color.js`, `test/color.test.js`
**What:** `colorsFor({repoId, branch})` per ARCHITECTURE.md: fnv1a -> hue, 4 discrete branch shades, dark tint hex, vivid frame hex.
**Verify:** Tests: deterministic across runs; two different repos differ in hue; same repo two branches differ in shade only; tint lightness stays in the readable band. `npm test` green.
**Commit:** `feat: color contract (repo->hue, branch->shade)`

## Step 5: State + hook entry (SessionStart)
**Files:** `src/state.js`, `src/tty.js`, `src/hook.js`, `src/adapters/frame-win.ps1`
**What:** Parse stdin JSON, resolve repo root + branch via `git -C` (no repo -> identity = cwd, no shade), emit tint + title via tty.js, spawn `adapters/frame-win.ps1` on first paint or color change (foreground-window handshake, terminal allowlist), cache HWND in state.json. Always exit 0.
**Verify:** Manual: `echo <fake-json> | node src/hook.js` in a scratch WT window tints it and paints the frame; state.json holds the HWND.
**Commit:** `feat: SessionStart hook - tint, frame, title`

## Step 6: UserPromptSubmit path
**Files:** `src/hook.js`
**What:** On prompt: recompute branch, re-emit tint + title `repo · branch · <60-char prompt>`, repaint frame from cached HWND (no new handshake). Prune stale sessions.
**Verify:** Manual fake-JSON run updates title with prompt snippet in under 50 ms (time it).
**Commit:** `feat: prompt-in-title on UserPromptSubmit`

## Step 7: Installer
**Files:** `bin/install.js`
**What:** Merge SessionStart + UserPromptSubmit hook entries into `~/.claude/settings.json`. Back up to `settings.json.aura-bak` first. Idempotent (re-run = no dup entries). `--uninstall` flag removes them.
**Verify:** Run on a COPY of settings.json; diff shows only the two hook entries added; re-run adds nothing.
**Commit:** `feat: npx installer with settings.json merge + backup`

## Step 8: Live QA - the 10-window test
**Files:** none (QA), findings -> CLAUDE.md Common Mistakes
**What:** Install for real. Open 6+ Claude Code windows: 3 repos x 2 branches. Send prompts in each.
**Verify:** Each repo shows a distinct stable hue; branch shades distinguishable; titles show latest prompts; no turn feels slower; closing/reopening a repo reproduces its color.
**Commit:** `docs: QA findings from live 6-window run`
